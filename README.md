# Local Reference Passport

**Track 3: Local Networks & Experience** · Power Learn Project Mini-Hackathon
**SDG 8 (Decent Work) · SDG 10 (Reduced Inequalities) · SDG 17 (Partnerships)**

## The problem
Skilled refugees can't get hired without local experience, and can't get local experience without being hired. The real gap is a lack of local references and networks.

## The solution
Local Reference Passport turns small paid tasks into verified proof:
1. **Work:** take paid micro-tasks from local businesses, ranked by skill match.
2. **Get endorsed:** businesses write a reference and can offer a warm introduction.
3. **Show proof:** the refugee gets a passport with verified jobs, local references, work hours, a trust level, a verification code and a visual local-network map.

## How it meets the evaluation criteria
- **Credential and skills verification:** every stamp is a task signed by a local business, plus a verification code.
- **Access and compliance readiness:** paid micro-tasks give a safe first step with a clear record of hours and pay.
- **Practical and market fit:** tasks come from neighbourhood employers and are matched to real skills.
- **Social and SDG impact:** decent work, reduced inequality and refugee–business partnerships.
- **Sustainability and scalability:** a lightweight tool that any city, NGO or sector can run.

## Built with
